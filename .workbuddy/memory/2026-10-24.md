# 2026-10-24

## 修复：3D 画布右键与浏览器默认行为冲突（前进/后退手势抢占）

- 根因：主 3D 视图用 drei `CameraControls`（camera-controls 库），`mouseButtons.right = ROTATE`；该库刻意不在 `pointerdown` 上调 `preventDefault`（dist 注释，仅 pointermove 阻止），且项目空闲态没有任何地方抑制画布原生右键 → 手势浏览器把"右键按下+移动"识别为前进/后退。
- 改动 1（核心）：`packages/editor/src/hooks/use-grid-events.ts` — `handlePointerDown` 对 `button === 2` 先 `preventDefault()` 再 return；`handleContextMenu` 一律先 `preventDefault()` 再转发 `context-menu`（该总线事件无消费者，无功能丢失）。
- 改动 2（兜底）：`packages/editor/src/components/editor/custom-camera-controls.tsx` — 相机控制 effect 中给 `gl.domElement` 加捕获阶段 `contextmenu` 拦截 + 右键 `pointerdown` 拦截，覆盖 grid 未挂载的场景（首人称/预览/加载中）。
- 已验证：R3F events 无 `defaultPrevented` 跳过分发逻辑，preventDefault 不影响相机旋转与工具事件；editor 包 tsgo 类型检查通过；use-grid-events、floor-aware-camera-controls、duplicate-hosted-mounted 测试全过。
- 局限：第三方鼠标手势扩展（crxMouse/鼠大侠等）可能不理会页面 preventDefault，需在扩展内加站点白名单；浏览器内置手势可被本修复压制。
